# spectral-matcher

`spectral-matcher` compares mass spectra from samples with each other and with reference libraries to find related signals and possible chemical candidates. A high-scoring match is a lead to investigate, **not proof** that a chemical is present.

The wider flock aims to turn mass-spectrometry samples and measurements into traceable candidate evidence, with an optional knowledge-graph export. This crate supports that work by building spectral networks, searching libraries, and combining search results.

**Start with the [flock overview](https://github.com/oolonek/flock-roadmap/blob/main/README.md)** for the big picture. For commands, configuration examples, parsing rules, output formats, and GUI integration, continue to the [technical guide](TECHNICAL.md).
